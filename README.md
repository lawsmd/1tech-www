# 1tech-www

Source for the [1tech.us](https://1tech.us) website. Plain HTML + CSS, no framework, no build step.

Deployed via **Cloudflare Pages** on push to `main`.

## Preview locally

```
python -m http.server 8000
```

Open `http://localhost:8000/`.

## About 1tech

1tech LLC is a solo consultancy in Wise County, Virginia, building custom software for small-town and Appalachian organizations.
